# Python To-Do List Manager

A simple command-line To-Do List Manager developed using Python.

## Features

- Add new tasks
- View existing tasks
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Automatically save tasks
- Load saved tasks using JSON

## Technologies Used

- Python
- JSON
- File Handling

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Shivamtripathi78/python-todo-list.git
```

2. Navigate to the project:

```bash
cd python-todo-list
```

3. Run the application:

```bash
python main.py
```

## Project Structure

```text
python-todo-list/
├── main.py
├── README.md
└── .gitignore
```

The application automatically creates tasks.json to store tasks.
